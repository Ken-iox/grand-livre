# Grand Livre

Application de budget personnel — locale, hors-ligne, sans cloud. Toutes les
données vivent uniquement sur l'appareil de l'utilisateur (IndexedDB) ; le
code hébergé ici ne sert qu'à l'installation (PWA via GitHub Pages).

## Installation (usage personnel)

1. Ouvrir [https://ken-iox.github.io/grand-livre/](https://ken-iox.github.io/grand-livre/) sur le téléphone
2. Menu du navigateur → « Ajouter à l'écran d'accueil »
3. L'app fonctionne ensuite hors-ligne, comme une app native
